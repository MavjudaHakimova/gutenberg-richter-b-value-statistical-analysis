## Исходные данные и воспроизводимость

В `data/` лежит компактная поставка, достаточная для повторения расчётов и построения рисунков. Черновые промежуточные файлы и тысячи невошедших изображений мы не включали.

| Файл | Содержание |
|---|---|
| `isc_mw_1960_2021.csv.gz` | Гомогенизированные величины Mw и регионы; основной анализ ограничен 1965–2021 годами |
| `neic_mb_1973_2021.csv.gz` | Исходные магнитуды mb и регионы NEIC; записи начинаются в 1973 году |
| `rfm_доверительные_интервалы.csv` | Годовой ряд b с 95% доверительными интервалами |
| `rfm_кривая_F_из_статьи.csv` | Опубликованные точки F-кривой для сверки |
| `bpositive_neic_итоги.csv` | Агрегированные региональные b-positive для порогов 3,5 / 4,0 / 4,5 |
| `bpositive_isc_итоги.csv` | Агрегированные региональные b-positive (все события / Mw ≥ 4,0) |

`run.py` заново рассчитывает RFM и MLE по ISC-каталогу. Таблицы b-positive взяты из финальной архивной обработки и используются для иллюстраций 6–8; их реализация находится в `src/bpositive.py`.

**О переименовании.** Таблица `isc_mw_1960_2021.csv.gz` в рабочем архиве называлась иначе — по фактическому происхождению это ISC/гомогенизированный каталог, а не NEIC, поэтому имя исправлено для ясности. Период анализа в статье — 1965–2021 годы, хотя в таблице есть записи до 1965 года.

**Гомогенизация магнитуд к Mw.** Метод общей ортогональной регрессии реализован в `src/gor.py`. Функция `prepare_homogenized_catalog` формирует каталог с магнитудами Mw по заданным коэффициентам и приоритетам шкал, а `fit_gor_deming` позволяет оценить сами коэффициенты по парам магнитуд при известном отношении дисперсий ошибок. Коэффициенты и порядок приоритетов в `src/gor.py` соответствуют тем, что использовались при построении каталога в `data/`.
